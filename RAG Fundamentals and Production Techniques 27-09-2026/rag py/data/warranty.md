# Warranty

All electronics carry a one year warranty against manufacturing defects,
starting from the delivery date.

The warranty does not cover physical damage, liquid damage, or damage from using
a charger that did not come with the product.

For a warranty claim, raise a ticket with the order id and a photo of the issue.
A pickup is arranged within 3 working days in serviceable areas.

Replacement is offered when repair is not possible. If neither is possible, the
order amount is refunded.

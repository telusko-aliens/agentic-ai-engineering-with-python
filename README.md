## 🎯 Course Philosophy

This course is built for **Python developers** who want to go beyond basic LLM integration and actually build **intelligent, autonomous AI systems**. You will learn how to design and ship agentic applications using the **OpenAI Agents SDK**, **LangChain**, **LangGraph**, **CrewAI**, the **Model Context Protocol (MCP)**, and **Agent2Agent (A2A)**, the same tools being adopted across the industry right now.

> The focus is not theory for its own sake. Every concept is tied directly to working Python code you can deploy in real projects. From understanding how LLMs work to building multi-agent systems that act, reason, and remember, this course takes you all the way to agents running in production. Every major stage ends with a practical, deployable project, not a toy demo.

## ⚡ Getting Started

> **Prerequisites:** Python 3.12+, [**uv**](https://docs.astral.sh/uv/), and an API key from your LLM provider (e.g. OpenAI), or a local model through **Ollama**.

```bash
# 1. Clone the repository
git clone https://github.com/telusko-aliens/agentic-ai-engineering-with-python.git
cd agentic-ai-engineering-with-python

# 2. Move into the session you want to run
cd "Getting Started with LangChain  23-08-2026/pythonlive"

# 3. Install dependencies (uv creates the virtual environment for you)
uv sync

# 4. Add your API key
cp .env.example .env        # then open .env and paste your key

# 5. Run any file
uv run telusko-lc.py
```

<details>
<summary><b>🐍 Prefer plain pip instead of uv?</b></summary>

```bash
cd "Getting Started with LangChain  23-08-2026/pythonlive"
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS / Linux
pip install langchain langchain-openai openai python-dotenv requests
python telusko-lc.py
```

</details>

> 💡 Each session folder is self-contained with its own `pyproject.toml`. Open the specific folder in your IDE and run it independently.

## 🔑 API Keys & Environment

Every project reads its credentials from a local `.env` file, so **no keys are ever committed to this repository**.

```bash
# .env
OPENAI_API_KEY=sk-your-key-here
```

- Get an OpenAI key from **https://platform.openai.com/api-keys**
- Copy `.env.example` to `.env` inside each session folder and paste your own key
- `.env` is already listed in `.gitignore`, keep it that way
- ⚠️ **Never** share or push your API key, and never hardcode it inside a `.py` file
- 💡 Want to practise without spending anything? Use **Ollama** to run open-source models locally

# Advance LangGraph (Part - 2) 15-11-2026 — agents

Agents in LangGraph: tools, recursion, memory and streaming.

Class source code for the **Agentic AI Engineering with Python** course.

## Setup

```bash
uv sync
cp .env.example .env    # then add your own API key
```
